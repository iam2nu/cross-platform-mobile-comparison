# Auto-Logbuch - Expo React Native

Vollständige 1:1 Umsetzung der Flutter Auto-Logbuch App mit GPS-Tracking.

## Quick Start

```bash
npm install
npx expo start
```

## Features

✅ Fahrzeugverwaltung  
✅ Wartungseinträge mit Kostenübersicht  
✅ GPS-Fahrtenbuch mit Live-Tracking  
✅ SQLite-Datenbank  
✅ TypeScript & React Navigation

Siehe [README.md](./README.md) für vollständige Dokumentation.
